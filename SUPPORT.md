# Support

## Community support

Open a [GitHub issue](https://github.com/BSN4/grpc-php-rs/issues) — use the
templates; the compatibility template exists because "works differently than
ext-grpc" reports are the most valuable ones this project gets. Issues are
answered on a best-effort basis.

## Priority support for companies

grpc-php-rs is maintained by one person and used in production by companies.
If that includes yours, [**sponsoring the project**](https://github.com/sponsors/BSN4)
comes with prioritized issue triage and a direct line to the maintainer —
sponsorship is what funds the compatibility ledger, the ecosystem test matrix,
and timely fixes when a Google SDK update changes behavior.

If you rely on this extension in production and cannot sponsor, an engineer's
time on reproductions and PRs is the next best contribution.
